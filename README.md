## 新增一本书

1. 在 `书籍/` 下新建以书名命名的目录。
2. 参考 [读书笔记模板](./书籍/模板/读书笔记模板.md) 添加资料。
3. 把原始书籍来源、版本、阅读进度记录清楚。
4. 将重要问题归入 `思想笔记/`，与原著论点分开。

## 整理原则

1. 区分**原著观点**、**个人理解**和**待验证假说**。
2. 保存出处、译本和日期，方便检索与核实。
3. 比较不同理论和反例，允许随证据修订观点。
4. 上传电子书全文前检查具体版本的版权和再分发许可。

> 此仓库可公开访问，避免上传敏感个人信息、账号密钥和无授权资料。
