## 新增规则

每本书建立独立目录；保存书名、作者、译本、阅读链接、读书笔记和阅读状态。引用内容标出处；个人推论与原著观点应有明确分界。

> 除非明确写明并确认相关许可，书籍目录不保存第三方 PDF 全文，只记录来源链接。
