## 三卷阅读提纲

1. **第一卷：资本的生产过程**——商品、货币、劳动力、剩余价值与资本积累。
2. **第二卷：资本的流通过程**——资本循环、周转和社会总资本再生产。
3. **第三卷：资本主义生产的总过程**——利润、平均利润、利息、地租等形式。
