## 三卷阅读提纲

1. **第一卷：资本的生产过程** — 从商品和货币开始，研究劳动力商品、剩余价值生产与资本积累。
2. **第二卷：资本的流通过程** — 研究资本循环、周转与社会总资本再生产。
3. **第三卷：资本主义生产的总过程** — 讨论利润率、平均利润、商业资本、利息、地租等形式。
