# 《资本论》｜核心概念索引

这是一份**初步学习提纲**，不是词句级的权威释义。概念在马克思著作中具有特定论证语境，深入阅读时应回到原文。

| 概念 | 理解提示 | 延伸问题 |
|---|---|---|
| 商品 | 为交换而生产的劳动产品；在论述中涉及使用价值与价值的区分 | 具有使用价值的东西一定是商品吗？ |
| 使用价值 | 物品满足某种需要的有用性 | 为什么有用不必然意味着有价值？ |
| 价值 | 在马克思的价值理论中，与社会必要劳动时间相关 | 价值与交易价格有哪些区别？ |
| 具体劳动与抽象劳动 | 从劳动的不同规定性理解商品二因素 | 二者如何在同一次劳动中体现？ |
| 货币 | 在商品交换中发挥一般等价物等作用 | 货币何时转化为资本？ |
| 劳动力 | 人的劳动能力，在特定社会关系中成为商品 | 劳动力价值与劳动创造的价值如何区分？ |
| 剩余价值 | 马克思用于分析雇佣劳动与资本增殖关系的核心概念 | 绝对剩余价值与相对剩余价值有什么不同？ |
| 资本积累 | 剩余价值再转化为资本的过程 | 积累与资本集中、资本积聚如何区分？ |
| 资本循环 | 资本在不同职能形式之间的运动 | 生产时间与流通时间有何作用？ |
| 利润 | 剩余价值在资本主义生产关系中的转化表现形式之一 | 为什么利润的表面形式会遮蔽其来源？ |

## 使用说明
- 读到每个概念时补充准确的卷、章、节。
- 对存在不同解释的术语，另附文献与相反观点。
- 将概念之间的关系画成图时，标注「据原著」「我的推论」或「待验证」。
