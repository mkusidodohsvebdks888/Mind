## 如何整理
- **问题**：想理解的现象是什么？
- **观察**：有哪些可确认的事实？
- **现有理论**：不同作者或理论如何解释？
- **个人假说**：自己的解释是什么？哪些地方仍不确定？
- **验证方法**：用什么案例、数据或推理去检验？
- **修订记录**：新证据出现后怎样更新观点？
